# Спомени+ (mobile-first прототип)

Лек мобилен прототип на ап за спомени с:
- login начален екран;
- отделна страница **Добави спомен** (форма за създаване);
- отделна страница **Timeline** с подредба по дата на събитие;
- страница **Map** с реални пинове върху карта;
- страница **People** (добавяне на хора + снимка + детайлен профил);
- страница **Tags**.

## Функционалности
- При създаване на спомен е задължително само полето за текст.
- Има поле за **дата на събитието** и timeline се подрежда по тази дата (най-новите първи).
- Има опционално поле за **предмет** (напр. фотоапарат, книга), което се показва в спомена.
- Има отделни тагове за:
  - общи тагове;
  - тагове за дейност;
  - тагове за емоция/чувство.
- В **People** може да добавиш име и снимка; при повторно добавяне на същото име снимката се обновява.
- Клик върху човек от **People** отваря детайлен профил със снимка и свързани спомени.
- Клик върху таг филтрира Timeline по съответния тип таг.
- Картата е с интеграция чрез **Leaflet + tile provider** (по подразбиране OpenStreetMap).
- В страницата **Map** се виждат всички добавени пинове.
- Данните се пазят в `localStorage` на браузъра (локално в устройството).

## Конфигурация на map provider
По подразбиране се ползва OpenStreetMap. Може лесно да се смени, като преди `app.js` зададеш:

```html
<script>
  window.APP_MAP_CONFIG = {
    tileUrl: 'https://{s}.tile.openstreetmap.org/{z}/{x}/{y}.png',
    tileAttribution: '&copy; OpenStreetMap contributors',
    center: [42.6977, 23.3219],
    zoom: 6,
  };
</script>
```

## Стартиране
```bash
python3 -m http.server 4173
```
После отвори:
- `http://localhost:4173` (локално)
- или `http://<IP-на-машината>:4173` от друго устройство в същата мрежа.
